# 📊 예산현액 뷰어 (Budget Viewer) — 일상경비교부액 기준

k에듀파인에서 다운로드한 **예산현액** 엑셀 파일을 로드하여, **일상경비교부액**을 기준으로 교부액, 지출액, 잔액을 직관적인 트리 구조로 분석해주는 데스크탑 애플리케이션입니다.

![App Screenshot](https://via.placeholder.com/800x450.png?text=Budget+Viewer+UI+Preview) <!-- 실제 스크린샷 업로드 후 링크 교체 권장 -->

## ✨ 주요 기능

- **실시간 데이터 분석**: k에듀파인 엑셀 파일을 즉시 파싱하여 일상경비 집행 현황을 시각화합니다.
- **다양한 분석 모드 지원**:
  - **자동분류(추천)**: 사업명 기준으로 유사 사업을 지능적으로 그룹화합니다.
  - **3세부/4세부 기준**: 에듀파인 코드 체계에 맞춘 정밀 분석을 지원합니다.
- **0원 행 숨기기**: 지출이나 잔액이 없는 불필요한 행을 제외하고 핵심 데이터만 골라 볼 수 있습니다.
- **강력한 필터링**: 세세부사업명, 사업명별로 원하는 데이터만 즉시 검색하고 필터링할 수 있습니다.
- **전문 보고서형 엑셀 내보내기 (v1.3 신규)**: 화면에 보이는 데이터를 실무에 즉시 활용할 수 있는 형태의 엑셀 문서로 변환합니다.
  - 금액 데이터를 자동 숫자로 변환하여 즉시 수식 연산 지원 (`SUM`, `AVERAGE` 등 가능)
  - 계층 구조(Depth)에 따른 배경색 지정, 틀 고정, 컬럼 자동 너비 등 시각적 위계 부여
- **동적 예산 열 표시 필터 (v1.4 신규)**: 원인행위액, 지출결의액 등 에듀파인에 있는 모든 금액 데이터를 동적으로 읽어들여 원하는 정보만 체크박스로 켜고 끌 수 있습니다. 숨겨진 열은 내보내기 문서에서도 깔끔하게 빠집니다.
- **자동 업데이트 확인**: 새로운 기능이 추가된 버전이 출시되면 앱 시작 시 자동으로 알림을 제공합니다.

## 🚀 시작하기

### 1. 프로그램 실행 (최신 버전 다운로드)
- [BudgetViewer Releases](https://github.com/exflyout/BudgetViewer/releases/latest) 페이지에서 최신 버전의 `BudgetViewer.exe`를 다운로드하여 실행합니다. (파이썬 설치 불필요)

### 2. 데이터 준비 (k에듀파인)
- **[재정사업관리]** → **[사업관리카드]** → **[예산현액]** 탭으로 이동합니다.
- **반드시 상단 옵션에서 [일상경비 포함]을 체크**한 뒤 [파일 다운]을 클릭하여 엑셀을 저장합니다.

### 3. 분석 시작
- 프로그램에서 **[엑셀 열기]** 버튼을 눌러 위에서 저장한 파일을 선택하면 즉시 분석 결과가 출력됩니다.

## 🛠 기술 스택
- **Language**: Python 3.11+
- **GUI Framework**: PySide6 (Qt for Python)
- **Data Processing**: Pandas, Openpyxl
- **Packaging**: PyInstaller
